# Task 7: powers from hover text (the knowledgeable) and learned by use. python tools/smoke.py . tools/smoke-gear-powers.txt build/smoke-gear-powers.log
# Fresh world, flat (server.properties level-type=minecraft\:flat for this run: a normal world may start the two in the sea), with the optional mods in run/mods.
# Brains off at once (at midnight they would dig in for the night, and from a hole the arrows hit the ground); /drifter shoot does the shooting
# at standing (NoAI, 1000 health) zombies, at night so the sun does not burn them (a newbie runs from a live one).
# The GearLore check runs every ~10 s: every read of a text belief comes 12 s or more after the item was given.
# What a stack does of its own (its enchantments; its lore or name, for one who reads) is never stored as a belief about the item (ruling R21):
# the line shows it as "(ENCHANT)" or "(LORE)" beside the stored "(TEXT)"/"(SEEN)" beliefs, for the stack named in the command.
# Expect, in order of the [gear] lines:
#  A   Vet (knowledge 0.9), the bow with the lore "Explodes on impact": "powers: explosive (LORE); text guess: explosive";
#  A2  Vet, a plain bow: "powers: none" (the lore is that one stack's, not the bow's);
#  A3  Newb (a newbie), the same lore'd bow: "powers: none; text guess: explosive" (it does not read);
#  B   Vet's plain iron sword: "powers: none";
#  C   Newb, its Flame bow: "powers: fire (ENCHANT)" (anyone sees an enchantment);
#  D   after both shot for 20 s: Newb, a plain bow: "powers: none", and no thought "found out Bow: fire" (Flame explains the fire);
#  E   Vet, who now carries a Fire Aspect iron sword too: the plain iron sword "powers: none", the Fire Aspect one "fire (ENCHANT)";
#  G   too_many_bows:flame_bow for Newb: "powers: none", "text guess: explosive, fire", no exception;
#  H   "/drifter gear powers": every gear item's text read on this dedicated server, the count of unreadable ones, no exception;
#  J   someone else's blast (a ghast-style fireball with no owner) at Newb's target while it shoots: still "powers: none" for Newb's bow;
#  K   a blast of its own there (a fireball made Newb's: the stand-in for an exploding arrow): "explosive 0.35 (SEEN)", thought "found out Bow: explosive";
#  L   a blast of its own beside Vet while it shoots: thought "found out the hard way: Bow explodes", a plain bow for Vet "explosive 1.00 (SEEN)";
#  M   Vet given the flame bow: "powers: explosive 0.75 (TEXT), fire 0.75 (TEXT)" (0.3 + 0.5 x 0.9; the item's own text, so stored).
# Then run tools/smoke-gear-powers2.txt on the same world: the beliefs are still there after the reload.
