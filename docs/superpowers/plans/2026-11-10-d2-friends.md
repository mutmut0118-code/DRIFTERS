# D2 Friends Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **This plan:** executed inline with superpowers:executing-plans, no subagents (the user's wish). No unit tests: the project
> is tested in the game. Each task's "test" is `./gradlew build` plus a headless smoke run (`python tools/smoke.py`) or a dev
> client script (`DRIFTER_CLIENT_TEST=<script>`), with the log lines named in the task.

**Goal:** Friendships between players and Drifters in Drifter: Civilizations: four stages built by talk and deeds, friend
perks, favors, endings, and a Friendship settings page with presets.

**Architecture:** The addon (`src/civ`, package `com.dinglebob.drifterciv`) owns everything: a world-saved record per
(Drifter, player) with the stage, one server tick loop that re-evaluates stages and fires perks, listeners on Drifter's
events, three addon goals, addon talk topics and chat lines as data. Drifter (`src/main`) only grows small hooks in
`com.dinglebob.drifter.api`, documented in docs/API.md in one block of its own.

**Tech Stack:** Java 21, Fabric 1.21.1 (Loader 0.19.5, API 0.116.17+1.21.1), Mojang mappings, Gson, Mod Menu (optional,
`modCompileOnly`).

**Spec:** `docs/superpowers/specs/2026-11-10-d2-friends-design.md`

## Global Constraints

- Fairness (DESIGN.md section 1): tips only from the Drifter's memory; food only from its own pockets; reach and player time; real beds.
- The addon reaches Drifter only through `com.dinglebob.drifter.api` and the things it hands out (`DrifterEntity`, `Home`, `Goals.Goal` and the activities/tasks a goal is built from); anything new goes into DrifterApi/DrifterEvents and docs/API.md in the same change. `DrifterApi.API_VERSION` 3 → 4.
- Never Bandits (disposition BANDIT now) or delvers as friends; temporary Drifters neither.
- Player speak in every line, several variants each, lower case, no NPC barks.
- Saved data versioned (`Version` int in the saved tag).
- Version 0.23.37 (bump the last number for every jar after); merge `claude/drifter-chat-expansion-574ebe` before installing if it has landed, keeping both sides of docs/API.md.
- Stay out of whim code and `drifter_whims` files.
- Performance: the friendship loop runs every 20 ticks per online player over Drifters within 32 blocks; nothing per tick per Drifter.

## Review Focus

- A player who is friends with someone in a town and then becomes wanted there for theft: the friend must not chase them, while everyone else does.
- Spam: typing "yeah" twenty times or answering every question in a row must not jump stages (daily diminishing returns per pair).
- Unloaded friends: `/drifterciv friends` and cooling must work for Drifters far away (records are world-saved, cooling uses game days, not loaded entities).
- A friend dying for good (permadeath) or leaving: the record shows "gone", no perks fire, no NPE on a missing entity.
- Two players and one Drifter: each player's stage is separate; whispers go only to their player.

**Interfaces (Produces):**
- `DrifterApi.whisper(DrifterEntity drifter, ServerPlayer player, String text)`: `Component.translatable("commands.message.display.incoming", <its name with the usual hover>, text)` styled GRAY+ITALIC, to that player only; server log `"<name> whispers to <player>: text"`; no Drifter overhears.
- `DrifterEvents.PLAYER_ANSWERED`: `(DrifterEntity drifter, ServerPlayer player, String topicId, String does, boolean yes)`, fired in `PlayerTalk.answered` for every answered topic question (before its own `does` runs).
- `DrifterApi.registerChatHandler(ChatHandler h)` with `interface ChatHandler { boolean heard(ServerPlayer player, DrifterEntity drifter, String text, @Nullable String intent); }`: called in `PlayerTalk.heard` right after the encounter check, before `Telling.told`; true = handled (the Drifter says nothing of its own).
- `DrifterApi.registerPlayerFacts(PlayerFacts f)` with `interface PlayerFacts { void add(DrifterEntity drifter, Player player, Map<String,Object> words, Set<String> flags); }`: called at the end of `Facts.player`, so `b:` conditions and `{b.word}` fill-ins can use them.
- `DrifterApi.setTrustFloor(TrustFloor f)` with `interface TrustFloor { double floor(DrifterEntity drifter, UUID player); }` (return `Double.NEGATIVE_INFINITY` for none): the daily drift's target is `max(target, floor)`.
- `DrifterApi.setNameNote(NameNote n)` with `interface NameNote { @Nullable String note(DrifterEntity drifter, ServerPlayer viewer); }`: appended on a new line to the name's hover in `ChatLines.line` (the hover set even when it's talking to nobody).
- `DrifterApi.setWhisperRule(WhisperRule r)` with `interface WhisperRule { boolean whisper(DrifterEntity drifter, ServerPlayer player, String key); }`: `PlayerTalk.reply` sends the line by `whisper` instead of aloud when the reply carries a `coords` var and the rule says so.
- `DrifterApi.familiarity(DrifterEntity d, UUID player)` → double (0 if unknown); `DrifterApi.addFamiliarity(DrifterEntity d, UUID player, String name, double change)`.
- `DrifterApi.memories(DrifterEntity d, MemoryKind kind)` → `List<MemoryEntry>` (a copy; `drifter.getMemory().find(kind, e -> true)`).
- `DrifterApi.spareFood(DrifterEntity d)` → `@Nullable Item` (PlayerTalk.spareFood); `DrifterApi.bring(DrifterEntity d, ServerPlayer p, Item item, int count)` (RequestGoal.ask GIVE).
- `DrifterApi.startTalk(DrifterEntity d, ServerPlayer p, @Nullable String topicId)` → `boolean` (PlayerChats.start != null).
- `DrifterApi.hostileOnSight(DrifterEntity d)` → `d.getSocial().disposition() == Disposition.BANDIT || d.isDelver()`.
- `DrifterApi.lastSeen(DrifterEntity d, UUID player)` → game time it last saw them, -1 never (`Relationship.lastSeenAt`).

### Task 3: Friendship records, stages and the loop

**Files:**
- Create: `src/civ/java/com/dinglebob/drifterciv/Friends.java` (SavedData `"drifter_civ_friends"`, the loop, stage rules, hooks wiring)
- Create: `src/civ/resources/data/drifter_civ/drifter_chat/friends.json` (lines: `friends.up.acquaintance` (none said: silent), `friends.up.friend`, `friends.up.best`, `friends.cooled`, `friends.back_from_cool`)
- Modify: `FriendCommands.java` (`/drifterciv friends`; debug `/drifterciv friends set <stage>` on the nearest Drifter you look at, `/drifterciv friends days <n>` to age every record of yours)
- Modify: `src/civ/java/com/dinglebob/drifterciv/DrifterCivilizations.java` (`Friends.register()`); `TownReputation.describe` caller (`/drifterciv town` adds "Friends here: a (friend), b (best friend)...")

**Interfaces (Produces):**
- `enum Stage { STRANGER, ACQUAINTANCE, FRIEND, BEST_FRIEND }`; `enum State { ACTIVE, COOLED, ENDED, GONE }`.
- `final class Bond { UUID drifter; UUID player; String drifterName; String playerName; Stage stage; State state; long since; long lastTogether; long talkDay; int talksToday; List<String> shared /* "topicId:yes|no", newest last, at most 24 */; long lastTip, lastFood, lastWelcome, lastFavor; @Nullable Favor favor; }` and `record Favor(String kind, long asked, long due, boolean promised)`.
- `Friends.bond(MinecraftServer s, UUID drifter, UUID player)` → `@Nullable Bond`; `Friends.stage(DrifterEntity d, Player p)` → `Stage` (STRANGER when none, or not ACTIVE); `Friends.isFriend(DrifterEntity d, Player p)` (ACTIVE and FRIEND or BEST_FRIEND); `Friends.of(MinecraftServer s, UUID player)` → `List<Bond>`; `Friends.end(DrifterEntity d, Player p, String why)`; `Friends.cool(MinecraftServer s, Bond b, String why)`.
- Stage rules (checked every 20 ticks for Drifters within 32 blocks of each online player; thresholds divided by `pace`); `ease` = 0.5 + Sociability + Forgiveness·0.5 − Vengefulness·0.5 (clamped 0.5 to 1.5; thresholds divided by it):
  - ACQUAINTANCE: familiarity ≥ 10 and trust > 0.
  - FRIEND: trust ≥ 50 and familiarity ≥ 30 and at least 2 shared opinions agreed (`:yes`) or a SAVED_IT deed.
  - BEST_FRIEND: trust ≥ 70 and familiarity ≥ 30·`bestFriendHarder`, at least 6 agreed shared opinions, and fewer than (Sociability ≥ 0.8 ? 4 : 2) best friends already.
  - Never down by trust alone (status holds; the floor keeps trust up); down only by `cool`/`end`.
- Trust floor (Task 1 hook): FRIEND 30, BEST_FRIEND 50, COOLED 10, else none.
- Player facts (Task 1 hook): flags `acq`, `pal` (friend or best), `bff`, `cooled`; words `shared` (a shared opinion's words, from the topic's `about`), `since_days`.
- Name note (Task 1 hook): "your acquaintance" / "your friend" / "your best friend" / "used to be friends".
- Cooling: `coolDays` > 0 and (now − `lastTogether`) ≥ coolDays·24000 → COOLED, line `friends.cooled` not said (nobody's there), chronicle-free. Back: COOLED, together 5 minutes (familiarity +1 seen) and trust ≥ 25 → ACTIVE at its old stage, line `friends.back_from_cool`. `lastTogether` = now whenever it sees the player (`DrifterApi.lastSeen`).
- Up a stage: line `friends.up.friend` / `friends.up.best` to the player aloud when `announce`; `/drifterciv friends` lists stage, where, since.
- Who: `!DrifterApi.hostileOnSight(d) && !d.isTemporary() && (!townsOnly || in a town)`; none at all with `on` false.
- Died for good (`DrifterEvents.DIED`, `comesBack` false) → GONE.

- [ ] **Step 1:** SavedData with `Version` 1, records keyed `drifter|player`; load/save every field.
- [ ] **Step 2:** The loop and the stage rules; hooks set in `register()`.
- [ ] **Step 3:** Commands and the `/drifterciv town` line.
- [ ] **Step 4:** `./gradlew build`; dev client script `run/friends-stages.txt`: spawn a Drifter near, `cmd drifter social <name> trust 55` (and familiarity 35), wait 200, `chat` nothing, check log for `friends.up` not yet (no shared opinions), `cmd drifterciv friends set friend`, `cmd drifterciv friends`, `cmd drifterciv friends days 11`, wait 100, `cmd drifterciv friends`. Expected: "friend", then "used to be friends".
